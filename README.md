# Kavana story chat prototype

A cinematic, browser-first story chat prototype shaped by product research into Kavana’s interactive AI-character experience.

## Run locally

```bash
npm run dev
```

Open `http://localhost:4173` in a browser. The server binds to `0.0.0.0` so it also works in a hosted preview.

## Included

- Browse dashboard with a continue-reading hero, story discovery, genre filters, saved stories, and recent stories.
- Interactive chat view with scene narration, character memory, suggested replies, free-form messages, simulated responses, and story progress.
- Responsive sidebar and mobile tab navigation.
- Search modal, save/share/profile feedback, story seed modal, and toast notifications.
- Original generated cover art in `assets/` and product findings in [`RESEARCH.md`](./RESEARCH.md).

This is a front-end prototype: chat responses are simulated in the browser and there is no backend or authentication layer yet.
